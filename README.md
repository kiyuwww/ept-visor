Lowest Level Dev: Hypervisor & Virtualization Framework
Репозиторий содержит низкоуровневые исходные файлы и ассемблерные заглушки для разработки собственного гипервизора (VMM — Virtual Machine Monitor) под архитектуры Intel (VT-x / EPT) и AMD (AMD-V / NPT).

📌 Основные компоненты
intel_vmm.cpp & intel_vmm_stub.asm — инициализация и логика гипервизора для процессоров Intel (VT-x), обработка переходов в режим VMX и выполнение низкоуровневых ассемблерных инструкций.

ept_common.cpp — управление расширенными таблицами страниц (Extended Page Tables, EPT) для трансляции физической памяти в средах Intel.

amd_svm.cpp & amd_npt.cpp — поддержка аппаратно-опосредованной виртуализации AMD-V (SVM) и вложенных таблиц страниц (Nested Page Tables, NPT).

vmexit.cpp — центральный обработчик перехватов и событий выхода из виртуальной машины (VM-Exit / VM-Intercept).

common.h — общие макросы, определения структур данных и служебные функции.

🛠 Технические особенности
Dual-Vendor Support: Поддержка аппаратных технологий виртуализации как Intel (VMX/EPT), так и AMD (SVM/NPT).

Низкоуровневая обработка VM-Exit: Быстрая обработка перехватов инструкций и прерываний на уровне ядра/гипервизора.

Прямое управление памятью: Настройка SLAT (Second Level Address Translation) для полного контроля над адресацией физической памяти гостей.

🚀 Сборка и требование к окружению
Компилятор: C++17 / MSVC или GCC/Clang с поддержкой Inline Assembly / YASM / NASM.

Платформа: x86_64 / x64.

Требования к CPU: Процессор с поддержкой виртуализации (Intel VT-x / AMD-V), включенной в BIOS/UEFI.
